🔧 Integration Information

This page demonstrates automatic progress tracking. The videos are automatically tracked when played.

Manual Integration Code:

<!-- Include the integration script --> <script src="http://localhost:3000/lms-progress-integration.js"></script> <!-- Initialize the tracker (or use data attributes) --> <script> const tracker = window.initializeLMSProgressTracker({ userId: '68aab7310e17c845daa50352', trainingId: '68ab07279782e8652d5b0e1c', moduleId: '68173662b95f4caae809067e', apiUrl: 'http://localhost:7000/api' }); // Manual progress tracking tracker.trackProgress('started', 0, 300, 'video_001'); </script>

API Endpoints Used:

  • POST /api/training/update-video-progress - Update video progress
  • GET /api/training/user-progress/{userId} - Get user progress
  • POST /api/training/sync-external-progress - Sync external data
